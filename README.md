# Data Science Portfolio

This repository contains the GitHub Pages portfolio for Zihao Shao's tourist mobility analysis.

## Publish with GitHub Pages

1. Create a public repository named `data-science-portfolio`.
2. Upload the contents of this folder to the repository root.
3. Replace `sora53997-cell` in `index.md` with your GitHub username.
4. Open **Settings > Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/(root)` folder, then save.
7. Open the URL shown in the Pages settings and verify all images and links.

The expected URL is:

```text
https://YOUR-GITHUB-USERNAME.github.io/data-science-portfolio/
```
